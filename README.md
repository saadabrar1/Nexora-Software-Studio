# Nexora Software Studio

Company website for **Nexora**, an AI-native product engineering studio based in Rawalpindi, Pakistan.

## What's inside

- `index.html` is the whole site in one file (HTML, CSS and JS). No build step.
- `covers/` holds the project cover images used in the case-study carousel.
- `videos/` holds the product demo videos opened from each case study.

## Sections

Hero with live product demos, services, case-study carousel with filters and a detail view, process, engagement models, proof, team, contact and footer.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Works on GitHub Pages as is: **Settings → Pages → Deploy from branch → `main` / root**.

## Tech

Plain HTML/CSS/JS, Plus Jakarta Sans and JetBrains Mono from Google Fonts, and [Motion](https://motion.dev) for the stats count-up and modal spring.
